## 🚀 Features

WPBruiser is an anti-spam and security plugin that:

- Blocks spam bots without CAPTCHA
- Prevents brute force attacks
- Protects WordPress forms (login, register, comments)
- Integrates with popular plugins (WooCommerce, Contact Form 7, etc.)
- Requires no external API calls
- Works invisibly in the background

## 🛠 Requirements

- PHP 7.3 or higher
- WordPress 5.8 or higher
- No additional PHP extensions required
- Modern browsers supporting ES6+ JavaScript

## 📦 Installation

1. Download the latest release
2. Upload to `/wp-content/plugins/goodbye-captcha/`
3. Activate through WordPress admin panel
4. Configure through Settings → WPBruiser
